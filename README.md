
# UniHelp 🎓

UniHelp is a full-stack campus community platform where students can ask questions, request help, share resources, and connect with other students.

## Features
- Secure login and email OTP verification
- Create, edit, and delete posts
- Offer, accept, and complete help requests
- Private ratings, trust scores, and help points
- Real-time chat and notifications
- Profile management and account deletion

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Other:** Socket.IO, bcrypt, Nodemailer

## Installation

```bash
git clone https://github.com/Swatiydv/UniHelp
cd UniHelp
npm install
```

Create a `.env` file with your MongoDB connection, session secret, and email credentials.

```bash
node app.js
```

Open `http://localhost:3000`.
